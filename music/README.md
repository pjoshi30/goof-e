Put one audio file here (MP3, M4A, WAV or OGG) to play while the arm moves, e.g. an
instrumental "La Vie en Rose" you own. The first file (alphabetically) is used. Audio files
in this folder are ignored by git. With no file, the app plays a soft generated ambient pad.

Included by default: gymnopedie-no1-satie.m4a, Erik Satie's Gymnopédie No. 1, converted from
https://commons.wikimedia.org/wiki/File:Erik_Satie_-_gymnopedies_-_la_1_ere._lent_et_douloureux.ogg
(public domain worldwide: released by its author Robin Alciatore via Musopen; the composition is
also public domain). Add another file whose name sorts first to use that instead.
